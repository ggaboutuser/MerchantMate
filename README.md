# MerchantMate Project

## "python -m streamlit run src/dashboard.py" in terminal to run

## Current structure
- `data/Online Retail.xlsx` dataset
- `src/data_loader.py` data loading and cleaning
- `src/analysis.py` business metrics and summaries
- `src/prompts.py` LLM prompts
- `src/ai_assistant.py` Groq integration
- `src/dashboard.py` Streamlit UI

## Setup notes
- `.env` stores your API key
- `.venv` is the Python virtual environment
- install dependencies with `pip install -r requirements.txt` once the virtual environment is activated
